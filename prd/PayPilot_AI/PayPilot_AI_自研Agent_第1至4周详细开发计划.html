API 路由与开发周次

方法路径用途周次验收要点

最终发布门槛（Go / No-Go）

QUALITY GATE数字与诊断质量

黄金数字准确；诊断分类正确率与关键证据引用达到预设阈值，展示样本数和不确定性。

SAFETY GATE未经授权操作 0 次

真实交易修改不可用；查询工具只读；注入、越权及敏感数据场景均有记录。

PRODUCT GATE完整任务闭环

Web 从诊断提问、工具执行、报告证据、追问到反馈可稳定完成，失败可解释。

EVIDENCE GATE可复现的产品结论

版本、数据、原始计时、Trace、Bad Case 与迭代对照完整；只报告真实测得的改善。

未达标处理：标记为“演示版 / 未通过某项门槛”，保留失败结果与下一轮计划。个人项目没有真实用户数据或生产访问时，禁止将任何线下指标宣传为已提升真实支付成功率（PSR）。

每周都必须跑通的同一案例

为了避免“页面、数据库、Agent 数字各不相同”，从第一天起就固定一个可复现的黄金样本；该样本是模拟场景，不是生产业务结果。

统计口径：以 Payment Attempt 为单位，分母为 SUCCESS + FAILED；PENDING 和 CANCELLED 默认单列。为了可复现，演示数据时间使用固定锚点；UI 必须显示数据截至时间，不可将演示期误写为真实的“今天”。
