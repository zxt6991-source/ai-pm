方法路径用途周次验收要点

Tool Registry 协议

backend/app/agent/tools/base.py · 协议草案
class Tool(Protocol):
    name: str
    input_schema: type[BaseModel]

    async def execute(self, args: BaseModel, context: ToolContext) -> ToolResult:
        ...

# ToolResult 必须包含：
# status, data, evidence_id, data_version, filters, errors
# 工具只暴露受控查询，不提供任意 SQL 执行能力。

自研状态机规划

状态与转移 · 设计草案
CREATED → PARSING → QUERYING → ANALYZING
                              ↓
                         RETRIEVING      # Week 3 接入
                              ↓
                         VALIDATING
                              ↓
                         COMPLETED

任意非终态 ─→ FAILED / CANCELLED
PARSING ─→ CLARIFYING ─→ PARSING
QUERYING ─→ INSUFFICIENT_DATA

# 规则：转移必须通过 state_machine.validate_transition()
# 终态不可重新执行；重试应创建新 run 或明确恢复点。

89.2%当前期 PSR · 1784/2000

统计口径：以 Payment Attempt 为单位，分母为 SUCCESS + FAILED；PENDING 和 CANCELLED 默认单列。为了可复现，演示数据时间使用固定锚点；UI 必须显示数据截至时间，不可将演示期误写为真实的“今天”。
